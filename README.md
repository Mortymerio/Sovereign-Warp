# 💠 M3WARP — Sovereign Code Interface

M3Warp is a high-performance, neural-enhanced IDE built for developers who demand speed, aesthetics, and intelligence. Powered by **Wails v3** and **Go**, it delivers a native experience with a cutting-edge **React/Monaco** frontend.

## 🚀 The Event Horizon Upgrade (v0.9.5)

We've implemented the **Event Horizon** roadmap, transforming the editor into a state-of-the-art workspace:

### 🎨 Spectral MiniMap
The minimap is no longer just for scrolling. It's a visual dashboard:
- **Git Heatmap**: Real-time visualization of line additions, modifications, and deletions.
- **Symbol Markers**: Instant identification of functions and classes on the minimap track.

### 🧭 Teleport Breadcrumbs
Navigate your codebase at the speed of thought:
- **Interactive Drops**: Click any path segment to explore siblings.
- **Fuzzy Filtering**: Integrated search within breadcrumb dropdowns to find files instantly.
- **Symbol Jump**: Zap-powered symbol navigation within the current file.

### 🧠 Neural Search V2
Our global search engine now features **Intelligent Ranking**:
- **Density Scoring**: Results are ranked by keyword proximity and relevance.
- **Contextual Awareness**: Snippets are perfectly centered to show the most relevant match.

### 💎 Sovereign Aesthetics
- **Glassmorphism HUD**: A translucent, blur-heavy interface for maximum focus.
- **Cyber Pulse**: Visual feedback on save and format operations.
- **Neural Themes**: Generate dynamic color schemes with AI-powered prompts.

## 🏗️ Architecture

- **Backend**: Go (Wails v3) with parallel indexing and search.
- **Frontend**: React 19 + TypeScript + Monaco Editor.
- **Intelligence**: Neural Service for symbol analysis and theme generation.
- **Performance**: Virtual pagination for large files (Chunk loading).

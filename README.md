Sovereign Warp is not just another text editor. It is a **High-Performance, AI-Native, and Visually Immersive IDE** designed for engineers who find VS Code too generic and heavy-weight IDEs like Eclipse too rigid. 

Built on the **Event Horizon** architecture, Warp focuses on the "Sovereignty of the Developer"—giving you total control over your environment, your data, and your AI assistant.

---

## 🚀 Why Sovereign Warp? (The "X" Factor)

While other IDEs focus on *features*, Warp focuses on **flows**. Here is what you can do in Warp that you can't do anywhere else:

### 🧠 1. Neural Symbol Telemetry (HUD)
Forget waiting for a CI/CD report to know your code is becoming a mess. Warp features a real-time **Neural HUD** that monitors every function and class as you type. 
- **Direct Feedback**: See Complexity and Integrity scores floating above your cursor.
- **Visual Integrity**: The editor physically reacts to code quality, giving you a "sixth sense" for technical debt before you even save.

### ⚡ 2. The Sovereign Extension Bridge
In VS Code, writing an extension takes days of boilerplate. In Warp, you can drop a script into your `.warp/extensions` folder and **execute it immediately** with full access to the IDE state. 
- **Ad-hoc Automation**: Build custom visualizers or refactoring tools in minutes using raw JavaScript/TypeScript that interacts directly with the Monaco engine.

### 🌌 3. Immersive "Cyber Pulse" Environment
Warp turns the act of coding into a high-feedback experience.
- **Neural Particles**: Every keystroke generates visual feedback based on your typing rhythm and project theme.
- **Dynamic Themes**: Use the **Neural Theme Engine** to change the soul of your IDE by typing prompts like "Blood", "Deep Sea", or "Acid Toxic".

### 🤖 4. AI-Native Architectural Context
While Copilot is a "chat in a box", Warp's **Cyber Assistant (Gemini)** is integrated into the core:
- **Spatial Awareness**: The AI knows exactly where your cursor is, what you're looking at, and the surrounding 400 lines of context.
- **One-Click Diff Comparison**: Review AI suggestions in a high-fidelity side-by-side comparison tool and apply them with a single click.

## 🛠️ Technology Stack

- **Core**: Go (Golang) for high-performance backend operations.
- **Frontend**: React 19 + TypeScript + Vite.
- **Editor Engine**: Monaco Editor (The power of VS Code, without the bloat).
- **Bridge**: Wails v3 (Native OS integration with web technologies).
- **Intelligence**: Google Gemini API integration.

## 📦 Getting Started

### Prerequisites
- [Go](https://golang.org/) (v1.25+)
- [Node.js](https://nodejs.org/) (v20+)
- [Wails v3](https://wails.io/)

### Installation
```bash
# Clone the repository
git clone https://github.com/Mortymerio/Sovereign-Warp.git

# Navigate to the project
cd Sovereign-Warp

# Run in Development Mode
wails3 dev
```

### Configuration
1. Open the **Settings Panel** (Gear icon in the Activity Bar).
2. Enter your **Gemini API Key**.
3. Hit "Refresh" to fetch your neural models.
4. Start coding at the speed of thought.
